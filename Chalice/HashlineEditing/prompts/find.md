List files whose path matches a glob pattern, using ripgrep. Returns matching paths relative to the working directory, one per line, sorted. Respects `.gitignore`, always skips `.git`, and skips binary and image files silently. `*` crosses directories, so `*.ts` matches `src/a.ts`; use `src/**/*.spec.ts` to anchor to a subtree. Results are capped at `limit` (default 1000) and at 2000 rows or 50KB; raise `limit` or narrow `path` / `pattern` when truncated. After finding a path, read it to get hashline anchors for editing.
